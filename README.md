# Ryan Webb Portfolio

A multi-route portfolio presenting Ryan Webb's product design, UX/UI, and
front-end development work.

## Stack

- Next.js
- React
- TypeScript
- CSS
- Static HTML export

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The production build is emitted as static HTML, CSS, and JavaScript in `out/`.
